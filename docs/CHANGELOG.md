## 升级指南

### 从旧版本升级

1. **备份数据**
   ```bash
   # 备份 localStorage 数据
   # 在浏览器控制台执行
   console.log(localStorage.getItem('xobi_settings'));
   ```

2. **更新代码**
   ```bash
   git pull origin main
   cd xobixiangqing/frontend
   npm install
   ```

3. **重新配置 API**
   - 访问 /settings
   - 确认 API Base URL 格式正确（以 /v1 结尾）
   - 测试连接

4. **清除缓存**
   ```bash
   # 清除浏览器缓存
   Ctrl + Shift + Delete
   ```

### 配置迁移

旧版配置会自动迁移，但建议检查：
- API Base URL 是否正确
- 模型配置是否完整
- 语言设置是否保留
